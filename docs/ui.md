# 界面设计

面板、聊天窗与两级管理页的视觉规范。改界面前先看这份文档，改完把新增的令牌补进来 —— 页面里不要出现一次性的颜色、字号和间距。

## 约束条件

界面在三个很窄的空间里工作，所有尺寸按最小值设计：

| 形态 | 尺寸 | 说明 |
| --- | --- | --- |
| 桌面面板 | 900 × 680 | 侧边栏 208 + 内容区 608 |
| 聊天窗 | 410 × 660 | 单列，气泡最大占 78% 宽 |
| 手机面板 | 屏宽，320 起 | 底部四标签，内容单列 |
| 管理页 | 最宽 760 居中 | Navigator 推出的整页 |

## 六条原则

1. **一屏一件事。** 每个 Tab 只有一个主标题、一个主按钮，其余动作降到次级。
2. **accent 只出现在「当前选中」和「主行动」。** 每只宠物自带一个 accent，它决定选中环、主按钮、进度条；不做整卡渐变，避免四张卡四个色调。
3. **发丝线代替阴影。** 卡片用 1px 边（`AppColors.line`）+ 白底；只有浮层（气泡、悬停卡片）给极淡投影。
4. **字号不小于 11。** 桌宠面板本来就小，10px 以下的中文会糊。
5. **间距走 4 的倍数。** 页面 20、卡片 20、元素 12 / 8，只有一个刻度尺。
6. **动效只用 transform / opacity，0.3s 内结束。** 长期驻留的窗口，动效不能抢注意力。

## 令牌

全部定义在 `app/lib/ui/theme.dart`，通过 `AppColors` / `Insets` / `Radii` / `AppType` / `Motion` 取用。

### 颜色

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `canvas` | `#F7F4EF` | 窗口内底色 |
| `surface` | `#FFFFFF` | 卡片、面板 |
| `surfaceAlt` | `#F5F1EA` | 输入框、内嵌块、未选中分段 |
| `surfaceSunken` | `#EFEAE1` | 列表 hover、禁用态 |
| `ink` | `#26211D` | 主文字 |
| `inkSoft` | `#6C6159` | 次要文字（白底 5.6:1） |
| `inkFaint` | `#786E66` | 辅助信息（白底 4.98:1，仍满足 AA） |
| `line` / `lineSoft` | `#E8E1D6` / `#F1ECE3` | 发丝边 / 分隔线 |
| `danger` / `success` / `warning` | `#C4443C` / `#2F7D53` / `#8F6417` | 语义色，各带淡底（`dangerTint` 等） |

`readableOn(bg)` 按相对亮度比较黑/白对比度取高者：宠物 accent 是浅橙时主按钮用深色字，是深紫时用白字，两档都能过 4.5:1。

### 间距 / 圆角 / 字号 / 动效

| 类别 | 刻度 |
| --- | --- |
| 间距 `Insets` | 4 / 8 / 12 / 16 / 20 / 24 / 32 |
| 圆角 `Radii` | 控件 12、卡片 16、面板 24、标签 8、胶囊 999 |
| 字号 `AppType` | 22 标题页 / 17 页头 / 15 卡片标题 / 13.5 正文 / 12.5 标签 / 11.5 辅助 |
| 字重 | 只用 w500 / w600 / w700 |
| 动效 `Motion` | 120ms 反馈、200ms 常规、280ms 布局 |

滑杆用 `divisions` 做 5% 档位，但刻度点必须 `SliderTickMarkShape.noTickMark` —— 否则默认刻度点会被误看成一条虚线。

## 组件

`app/lib/ui/common.dart`：

| 组件 | 用途 |
| --- | --- |
| `AppCard` | 白卡 + 发丝边；`onTap` 时自带水波纹 |
| `GlassCard` | 面板外框（兼容旧名），无重阴影 |
| `PillButton` | 主/次按钮，`filled` 切层级；悬停 1.02、按下 0.97。**`onTap` 必须显式挂上**：只写 `onTapDown` / `onTapUp` 时手势竞技场不会识别成点击，按钮只有按下动效、永远不触发回调 |
| `RoundIconButton` | 工具栏圆形按钮，悬停出浅底，默认 34 |
| `AppSegmented<T>` | 分段选择，选中项浮起一层白底 |
| `SettingRow` | 标题 + 说明 + 右侧控件；`help` 有值时整行 Tooltip + ⓘ；行高 45（开关等比缩到 34 盒） |
| `TagChip` | 性格、状态标签，accent 淡底 + 加深文字 |
| `AppBanner` | info / success / warning / danger 状态条 |
| `AppPageHeader` | 页面主标题 + 副标题 + 右侧动作 |
| `AppField` | 小标题在上、输入框在下 |
| `DashedBox` | 虚线区（照片选择、新建卡片） |
| `EmptyHint` | 圆底图标 + 一句说明 |
| `SoftTile` | 可点卡片，悬停浮 2px、选中 accent 描边 |

功能说明统一走 `FeatureHelp`：正文不放大段解释，鼠标悬停（触屏长按）才展开，标题旁一个 ⓘ。

## 各界面要点

### 面板（`panel_view.dart` / `panel_chrome.dart`）

- 侧边栏 208：品牌 → 「宠物」组（我的宠物 / 照片生成）→「应用」组（设置 / 智能体）。智能体保留下钻图标，因为它是养宠物之外最重要的能力。
- 顶部 16px 拖动把手，鼠标形态是 `move`。
- 内容卡片内边距 24 / 20，四个 Tab 共用 `AppPageHeader`，标题基线一致。

### 我的宠物（`gallery_tab.dart`）

- 所有卡片共用同一套中性渐变底，宠物图不再被 per-card 颜色干扰。
- 选中态 = accent 描边 + 白底「使用中」角标；官方/我的标签左上角。
- 重命名、编辑人设与删除收进右下角「⋯」菜单，卡片只留一个入口。
- 「让它表演」是一条工具条（走一走 / 跑一圈 / 躺下求摸 / 逗一下 / 转个圈），窄屏自动换行。

### 照片生成（`create_tab.dart`）

- 四步进度条：照片 → 抠图 → 性格 → 领养，进度来自 `generationProgress`。
- 未选照片时是虚线区 + 一键选择；选完显示原图 + 「换一张」。
- 风格三选一做成等宽卡片，选中打勾，不再用一排 chip。

### 人设（`persona_page.dart`）

- 整页编辑，入口两个：设置 →「宠物人设」卡片的「编辑人设」，以及宠物卡「⋯」菜单 →「编辑人设」。
- 三段：身份（名字 / 招呼语 / 口头禅）、性格（可增删的标签 chip）、说话风格（语气 + 人格提示词，
  可展开看宠物包自带的写法、一键「用默认」）。
- 人设存 `AppSettings.petPersonas`，不回写宠物包：内置宠物是只读 asset，且「恢复默认」只要删覆盖项。
  读取统一走 `AppSettings.personaOf(pet)`，所以聊天、招呼语、主动搭话、卡片标签用的是同一份数据。
- 保存时会把空字段填回宠物包默认值；全部清空的性格标签也回退默认，避免出现空招呼语与空 traits。

### 设置（`settings_tab.dart`）

- 密度：行高 45（行内边距 5、开关 34、分割线 1），900×680 下一屏能完整放下 9 行并露出下一组标题。
  想看更松的行距就调 `SettingRow` 的 vertical padding，别去动开关的视觉尺寸 —— 40 是 M3 的硬编码下限。

- 顶部「外观 / 人设 / 对话 / 语音 / 形象 / 更新 / 数据」七个锚点，点击滚到对应分组（`Scrollable.ensureVisible`）。
- 每个分组 = 小节标题 + 一张白卡；卡片内行与行之间用缩进发丝线分隔。
- 危险动作（清空对话）单独放在「数据」分组，按钮用 danger 色。
- 下拉、开关、输入框都走主题，不在页面里写颜色。

### 聊天（`chat_view.dart`）

- 头部：头像 + 昵称 + 成长标签 + 后端状态；右侧朗读 / 记忆 / 清空 / 收起。
- 空态给三条可点的开场建议（摸摸头 / 看磁盘空间 / 讲个笑话），不是只摆一张图。
- 气泡最大宽度按容器 78% 计算，用户气泡用 accent + `readableOn` 前景。
- 任务状态条沿用 `AgentActivity`，颜色改用语义令牌。
- 整段对话包在 `SelectionArea` 里，可以直接选文字复制工具输出。

### 智能体 / 记忆（`manage_page.dart` / `memory_page.dart`）

- 五段用 `AppSegmented`；内容最宽 760 居中，长说明一律是「标题 + 一行摘要 + Tooltip」。
- 权限页把「一键暂停」提成独立卡片，出问题时第一眼能找到。
- 记忆页按天卡片：日期头（今天/昨天/前天 + 星期 + 条数）→ 日结摘要（accent 竖条引文，正文不用斜体）→ 逐条情景。
- 情景行固定三栏：40px 时间列（HH:mm）→ 圆点 → 正文；`importance ≥ 3` 的强约定用实心 accent 圆点加粗字色，
  非 chat 类型与 tag 收在正文下方的 10.5px 元信息行，不再和时间挤在同一行。
- 单日删除与全部忘掉分开。

## 无障碍检查清单

- [x] 正文对比度 ≥ 4.5:1：`inkSoft` 白底 6.0:1、`inkFaint` 白底 5.0:1；accent 上的文字由 `readableOn` 计算。
- [x] 大字号与图标 ≥ 3:1：`inkFaint` 只用于 11.5px 以上的辅助信息，不承载关键动作。
- [x] 触控目标：桌面按钮高 38 / 密集 30，图标按钮 32–34；手机底部标签整块可点。
- [x] 键盘：`Esc` 收起聊天/面板；所有图标按钮带 Tooltip；`focusColor` 由主题统一给。
- [x] 语义：标题用真实文本层级（22 / 17 / 15 / 13.5），不靠字号硬编码堆层级。
- [x] 状态不只靠颜色：离线用「未连接」文字 + 图标，任务失败有错误图标与文案。
